# Simulation Models

NO_HARDWARE_ACTIONS_EXECUTED: true
HARDWARE_ACCEPTANCE: PENDING_HW

The TFDU6102 models are digital behavior models for offline verification. They
are not SPICE models, optical path models, supply integrity models, layout
models, or datasheet-equivalent electrical models.

Use these models to check RTL control, polarity, startup sequencing, bounded
TX pulses, active-low RX behavior, and pulse-level smoke tests.
