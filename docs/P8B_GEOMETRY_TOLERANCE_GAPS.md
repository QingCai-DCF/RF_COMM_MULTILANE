# P8B geometry tolerance gaps

Worst-case geometry acceptance is `PENDING_WITH_EXPLICIT_GAPS`. Unknowns are represented as `null`, never zero.

| Parameter | Current status | Needed for | Later gate | Blocking scope |
|---|---|---|---|---|
| radial eccentricity | PENDING_D13_OR_MECHANICAL_FREEZE | path/incidence symmetry | D13 | final rotating optical hardware |
| axial runout | PENDING_FINAL_MECHANICAL | out-of-plane ray angle | P13 | final rotating optical hardware |
| rotor/stator center offset | PENDING_FINAL_MECHANICAL | all-lane geometry | P13 | final rotating optical hardware |
| rotor module angle error | PENDING_FINAL_MECHANICAL | overlap and rotating alignment | P13 | final rotating optical hardware |
| stator module angle error | PENDING_FINAL_MECHANICAL | nearest-module delta | P13 | final rotating optical hardware |
| rotating/fixed PCB tilt | PENDING_FINAL_MECHANICAL | 3-D incidence | P13 | final rotating optical hardware |
| TFDU optical-axis error | PENDING_OPTICS | usable FOV margin | OPTICS | final rotating optical hardware |
| window refraction model | PENDING_OPTICS | effective ray direction | OPTICS | final rotating optical hardware |
| baffle occlusion mask | PENDING_OPTICS | usable overlap | OPTICS | final rotating optical hardware |
| thermal radial growth | PENDING_ENVIRONMENT | gap/path/incidence | ENVIRONMENT | final rotating optical hardware |

The machine-readable ledger is generated by `scripts/run_p8b_geometry_gate.py`. Its sensitivity notes and later-gate owners are canonical for P8B evidence. No gap changes `ROTATION_ACCEPTANCE=PENDING_FINAL_MECHANICAL`.
