# Project Status pointer

```text
DOCUMENT_STATUS: NON_CANONICAL_POINTER
CANONICAL_STATE: config/project_state.json
GENERATED_STATUS: PROJECT_STATUS.md
```

Current project status is generated at the repository root in [`PROJECT_STATUS.md`](../PROJECT_STATUS.md) from [`config/project_state.json`](../config/project_state.json). Historical pre-V3.1 snapshots are retained under `docs/legacy_stage_rules/` and must not override the machine state.
