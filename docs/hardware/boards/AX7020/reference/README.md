# AX7020 Local Reference Package

The raw vendor/reference package remains at repository-local `hardware_AX7020/` and is not committed. Its per-file names, sizes, SHA256 values, and dispositions are recorded in `manifest.json`.

This directory is reference inventory only. Vendor binary size and redistribution terms were not established, so the raw files are `LOCAL_ONLY_WITH_TRACKED_MANIFEST`. The manifest and this README do not define a project profile, role, connector allocation, pinmap, XDC, or hardware acceptance result.

Any future canonical AX7020 profile must be created separately under the profile boundaries defined by `AGENTS.md` and `PROJECT_CONSTRAINTS.txt`.
