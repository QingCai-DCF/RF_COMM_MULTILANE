The M6 scripts under `scripts/hw/` are hardware preparation wrappers only.
They default to `REFUSED_NO_ALLOW_HARDWARE`, emit the active profile hash and
hash manifests, and only run hardware paths when the caller passes
`-AllowHardware`. Authorized lane run wrappers force a final shutdown wrapper
call and require `SHUTDOWN_EXIT=0` or `TFDU_SHUTDOWN_PROGRAMMED` in the
shutdown evidence.

The shutdown bitstream is not generated by M6 and is not present in the new
workspace at `shutdown_bitstream/tfdu_shutdown_j10_j11.bit`; an authorized
hardware run must provide or build that artifact before shutdown can pass.
